# 1 定义
设函数$f(x)$在区间$I$上有定义，若对于区间$I$上任意两点$x_{1}$，$x_{2}$，及任意$\lambda\in(0,1)$，都有$f(\lambda x_{1}+(1-\lambda)x_{2})\leq\lambda f(x_{1})+(1-\lambda)f(x_{2})$，则称函数$f(x)$在区间$I$上是凹函数；若都有$f(\lambda x_{1}+(1-\lambda)x_{2})\geq\lambda f(x_{1})+(1-\lambda)f(x_{2})$，则称函数$f(x)$在区间$I$上是凸函数。当等号仅在$x_{1}=x_{2}$或$\lambda = 0$或$\lambda = 1$时成立，函数是严格凹凸的。

利用二阶导数判断首先，对函数$y = f(x)$求一阶导数$f^\prime(x)$。然后，对一阶导数$f^\prime(x)$再求导，得到二阶导数$f^{\prime\prime}(x)$。如果在区间I上，$f^{\prime\prime}(x)>0$，那么函数$y = f(x)$的图像在区间I上是凹的；如果在区间I上，$f^{\prime\prime}(x)<0$，那么函数$y = f(x)$的图像在区间I上是凸的
