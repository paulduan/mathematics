极坐标系是一种二维坐标系统 ，与常见的笛卡尔直角坐标系不同，它用距离和角度来确定平面上点的位置。以下是相关介绍：
### 0.1.1 构成要素
- **极点**：平面上选定的固定点，类似于直角坐标系中的原点 。
- **极轴**：从极点引出的一条射线，通常取水平向右方向（对应直角坐标系的$x$轴正半轴 ）。
- **极径**：平面上一点到极点的距离，用$r$（或$\rho$ ）表示，$r\geq0$ ，$r = 0$时表示极点 。
- **极角**：以极轴为始边，逆时针旋转到该点与极点连线所形成的角，用$\theta$表示，角度单位通常是弧度或度，取值范围一般是$[0, 2\pi)$  ，但也可为负（表示顺时针旋转 ） 。点的极坐标表示为$(r,\theta)$ 。 
### 0.1.2 与直角坐标系转换
- **极坐标转直角坐标**：若点的极坐标为$(r,\theta)$ ，其直角坐标$(x,y)$ 满足$x = r\cos\theta$ ，$y = r\sin\theta$ 。
- **直角坐标转极坐标**：对于直角坐标$(x,y)$ ，极径$r = \sqrt{x^{2}+y^{2}}$ ，极角$\theta$满足$\tan\theta = \frac{y}{x}(x\neq0)$ ，根据$(x,y)$所在象限确定$\theta$值 。 
### 0.1.3 常见曲线极坐标方程
- **圆**：圆心在极点，半径为$a$的圆方程是$r = a$ ；圆心在$(a,0)$ ，半径为$a$的圆方程是$r = 2a\cos\theta$ 。
- **直线**：过极点且与极轴夹角为$\alpha$的直线方程是$\theta = \alpha$ ；不过极点且与极轴夹角为$\alpha$ ，与极点距离为$p$的直线方程是$r\cos(\theta - \alpha)=p$ 。
- **阿基米德螺线**：方程为$r = a\theta$（$a$为常数 ） 。
- **玫瑰线**：方程为$r = a\cos k\theta$或$r = a\sin k\theta$ ，$k$为整数时，$k$奇有$k$瓣 、$k$偶有$2k$瓣 。
