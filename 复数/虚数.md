# 1 定义
在数学中，虚数是指可以表示为实数与虚数单位乘积的数 ，是复数的一部分。具体定义如下：
- **定义形式**：虚数通常写成$a + bi$ 且$b\neq0$ 的形式，其中$a$、$b$是实数，$i$是虚数单位，且满足$i^2 = -1$ (注意 这里并没有定义 $\cancel{i=\sqrt{-1}}$)。当$a = 0$且$b\neq0$时，$bi$称为纯虚数 ，比如$3i$ ；
- **从幂的角度**：偶指数幂是负数的数定义为纯虚数。例如，若$x^2\lt0$（$x$为未知数） ，此时$x$为纯虚数。

# 2 性质
- **虚数单位的幂次规律**：虚数单位$i$的幂次具有周期性规律，$i^1 = i$，$i^2 = -1$，$i^3 = i^2 \cdot i = -i$，$i^4 = (i^2)^2 = (-1)^2 = 1$。此后幂次以$4$为周期循环，即$i^{4n + 1}=i$，$i^{4n + 2}=-1$，$i^{4n + 3}=-i$，$i^{4n}=1$（$n$为整数）。
- **共轭虚数性质**：若$z = a + bi$，则其共轭虚数$\overline{z}=a - bi$。两个共轭虚数的乘积是实数，即$z\cdot\overline{z}=(a + bi)(a - bi)=a^2 + b^2$。
- **虚数的模的性质**：对于虚数$z = a + bi$，其模$\vert z\vert=\sqrt{a^2 + b^2}$。模具有非负性，即$\vert z\vert\geq0$，且$\vert z_1\cdot z_2\vert=\vert z_1\vert\cdot\vert z_2\vert$，$\left\vert\frac{z_1}{z_2}\right\vert=\frac{\vert z_1\vert}{\vert z_2\vert}$（$z_2\neq0$）。

# 3 运算法则
- **加法法则**：$(a + bi)+(c + di)=(a + c)+(b + d)i$。
- **减法法则**：$(a + bi)-(c + di)=(a - c)+(b - d)i$。
- **乘法法则**：$(a + bi)\cdot(c + di)=ac + adi + bci + bdi^2=(ac - bd)+(ad + bc)i$。
- **除法法则**：先将分母实数化，即给分子分母同时乘以分母的共轭复数（实部不变，虚部取相反数），然后进行化简
- $\frac{a + bi}{c + di}=\frac{(a + bi)(c - di)}{(c + di)(c - di)}=\frac{ac - adi + bci - bdi^2}{c^2 + d^2}=\frac{(ac + bd)+(bc - ad)i}{c^2 + d^2}$。
# 4 复数
形如$a + bi$（$a$、$b$均为实数）的数 ，其中$i$称为虚数单位，满足$i^2 = -1$ 。通常记复数为$z = a + bi$ ，$a$称为其实部 ，记作$\mathrm{Re}(z)$；$b$称为其虚部 ，记作$\mathrm{Im}(z)$ 。
 - **特殊情况**：
    - 当$b = 0$时，复数$z = a$，此时复数为实数 。例如$5$可写成$5 + 0i$ ，是实数。 
    - 当$a = 0$且$b\neq0$时，复数$z = bi$，称为纯虚数 。比如$4i$ ，即$0 + 4i$ ，是纯虚数。 
 - **复数集**：虚数和实数构成的集合称为复数集或复数域，常用$\mathbb{C}$表示 。
 - **复数相等**：对于两个复数$z_1 = a_1 + b_1i$ ，$z_2 = a_2 + b_2i$ ，当且仅当$a_1 = a_2$且$b_1 = b_2$时 ，称$z_1$与$z_2$相等，记作$z_1 = z_2$ 。
